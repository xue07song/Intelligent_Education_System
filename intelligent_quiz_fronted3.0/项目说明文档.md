# 智能题库管理系统 - 项目说明文档

## 一、项目概述

智能题库管理系统是一个前后端分离的 Web 应用，用于管理课程题库中的题目。支持题目的增删改查、多条件搜索、分页浏览、统计概览等功能。数据库中预置了大学计算机基础相关的题库数据（涵盖计算思维、计算机基础、Python 程序设计、人工智能等 10 个章节，约 400 道题目）。

---

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端** | Vue 3 + Vite + Axios | 单页应用，组合式 API（`<script setup>`） |
| **后端** | Express 5 + Node.js | RESTful API，MVC 分层架构 |
| **数据库** | MySQL 8.0 + mysql2 | 连接池，utf8mb4 字符集 |
| **开发工具** | npm、nodemon、Vite Dev Server | 热重载开发体验 |

## 四、基本逻辑

### 4.1 整体架构

```text
┌──────────────┐     HTTP/Axios      ┌──────────────┐     SQL      ┌──────────┐
│   前端 Vue    │  ←──────────────→   │  后端 Express │  ←──────→   │  MySQL   │
│  (端口 5173)  │   localhost:3000    │  (端口 3000)  │             │ program1 │
└──────────────┘                     └──────────────┘             └──────────┘
```

### 4.2 前端数据流

```text
用户操作 → 子组件 emit 事件 → App.vue 处理 → 调用 api/question.js
→ 经过 request.js（拦截器加 Token）→ 发 HTTP 请求到后端
→ 后端返回 JSON → request.js 响应拦截器剥离外壳 → 更新响应式状态
→ Vue 自动重渲染子组件 → 用户看到新数据
```

**关键代码链路（以加载列表为例）：**

1. [main.js](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/main.js) 启动应用，挂载 App.vue
2. [App.vue](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/App.vue) 的 `onMounted` 调用 `loadData()`
3. `loadData()` 调用 [api/question.js](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/api/question.js) 的 `getQuestions(params)`
4. `getQuestions` 调用 [utils/request.js](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/utils/request.js) 封装的 Axios 实例
5. 请求发往 `http://localhost:3000/api/v1/questions?page=1&pageSize=20`

### 4.3 后端请求处理链路

```text
HTTP 请求到达 app.js
→ CORS 中间件 + JSON 解析
→ 路由匹配 /api/v1/questions → routes/question.js
→ validator 中间件校验参数
→ questionController 解析请求参数
→ questionService 执行业务逻辑（查重、错误处理）
→ questionModel 执行 SQL 查询 MySQL
→ response.js 封装统一响应格式 { code, message, data }
→ 返回 JSON 给前端
→ 如有异常，errorHandler 统一捕获
```

**后端分层职责：**

| 层级 | 文件 | 职责 |
|------|------|------|
| 路由层 | [routes/question.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/routes/question.js) | 定义 URL 与控制器的映射 |
| 控制器层 | [controllers/questionController.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/controllers/questionController.js) | 解析 req 参数，调用 Service，封装响应 |

| 模型层 | [models/questionModel.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/models/questionModel.js) | 直接操作数据库，执行 SQL |

## 五、API 接口列表

所有接口前缀：`http://localhost:3000/api/v1`

| 方法 | 路径 | 功能 | 参数位置 |
|------|------|------|----------|
| GET | `/questions` | 分页查询题目列表 | query（page, pageSize, 关键词, 题型, 难度, 章节, 出题人） |
| GET | `/questions/:id` | 查询单个题目 | path（id） |
| GET | `/questions/search?kw=xxx` | 关键词搜索 | query（kw/keyword） |
| GET | `/questions/statistics` | 获取统计信息 | 无 |
| POST | `/questions` | 新增题目 | body（完整题目对象） |
| PUT | `/questions/:id` | 更新题目 | path（id）+ body（更新字段） |
| DELETE | `/questions/:id` | 删除题目 | path（id） |
| GET | `/health` | 健康检查 | 无 |

**统一响应格式：**

```javascript
// 成功
{ "code": 0, "message": "操作成功", "data": {...} }

// 分页
{ "code": 0, "message": "操作成功", "data": { "list": [], "total": 100, "page": 1, "pageSize": 20, "totalPages": 5 } }

// 失败
{ "code": 40401, "message": "题目不存在", "errors": null }
```

## 六、核心功能说明

### 6.1 分页查询（带多条件筛选）

前端 [App.vue](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/App.vue) 的 `loadData()` 拼装查询参数：

```javascript
const params = { page: page.value, pageSize: pageSize.value };
if (filters.关键词) params.关键词 = filters.关键词;
if (filters.题型) params.题型 = filters.题型;
// ...
```

后端 [questionModel.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/models/questionModel.js) 的 `findAll()` 动态拼装 WHERE 条件和分页 SQL：

```javascript
const whereClause = conditions.length > 0 ? `WHERE ${conditions.join(' AND ')}` : '';
const offset = (page - 1) * pageSize;
const [rows] = await pool.query(
    `SELECT * FROM ${TABLE} ${whereClause} ORDER BY id DESC LIMIT ? OFFSET ?`,
    [...params, pageSize, offset]
);
```

### 6.2 新增题目（含查重）

1. 前端 `generateId()` 根据当前列表最大 ID 生成新 ID（如 Q010）
2. 后端 [questionService.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/services/questionService.js) 先 `findById` 查重，已存在则抛 409 错误
3. [validator.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/middlewares/validator.js) 校验 id、题目、题型、难度合法性
4. 通过后执行 INSERT

### 6.3 统计信息

后端 [questionModel.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/models/questionModel.js) 的 `statistics()` 一次返回四维统计：

```javascript
return {
    total,           // 题库总量
    byChapter,       // 各章节数量
    byType,          // 各题型数量
    byDifficulty,    // 各难度数量
    byCreator,       // 出题人 TOP10
};
```

前端在 `onMounted` 和增删改成功后调用 `loadStats()` 刷新顶部统计栏。

### 6.4 错误处理机制

**后端**：[errorHandler.js](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/src/middlewares/errorHandler.js) 统一捕获：

- `ER_DUP_ENTRY` → 409 数据重复
- `ER_NO_SUCH_TABLE` → 500 数据库未初始化
- Service 层抛出的 `statusCode` 错误 → 对应 HTTP 状态码
- 其他未知错误 → 500

**前端**：[request.js](file:///c:/Users/gaoxu/intelligent-quiz-frontend2.0/src/utils/request.js) 响应拦截器：

- `code === 0` → 返回 `data`
- `code !== 0` → 抛出 Error
- HTTP 4xx/5xx → 控制台打印日志 + 抛出错误
- 业务代码 catch 后通过 `showToast()` 展示给用户

## 七、配置与启动

### 7.1 数据库配置

后端 [.env](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/.env.example) 文件：

```env
DB_HOST=localhost
DB_USER=root
DB_PASS=你的MySQL密码

```

数据库初始化：执行 [init.sql](file:///c:/Users/gaoxu/intelligent-quiz-backend3.0/init.sql) 建库建表，或导入 `mysql库.sql` 恢复完整数据。

### 7.2 启动步骤

```bash
# 1. 启动 MySQL，确保 program1 数据库和 题库1 表存在

# 2. 启动后端
cd intelligent-quiz-backend3.0
npm install
npm run dev          # 监听 http://localhost:3000

# 3. 启动前端
cd intelligent-quiz-frontend2.0
npm install
npm run dev          # 监听 http://localhost:5173
```
